# Where the sounds come from

Every synth model in MPK Synth is built to sound like a specific instrument, and its sound
has to come from data about that instrument, not from taste.

**The rule, for every model (Poly 106 now; Voyage, Raw 20, Patch 26 and Big 80 next):**

1. **Presets are the instrument's own patches.** Use its factory patches (or patch sheets
   published by the maker) wherever they exist, copied as data with their original names
   and numbers. Do not write presets by ear. If an instrument has no stored factory patches
   (the MS-20, ARP 2600 and CS-80 have none, or few), use patch charts published by the
   maker or in its manuals, and say which.
2. **Controls behave like the instrument's.** Ranges, curves and timings come from the
   service manual, the owner's manual specifications, the firmware where there is one, or
   measurements of real units, in that order of preference.
3. **Every number has a source.** Each model has a page here listing its sources, how each
   stored value maps onto the model's controls, and, honestly, what is still an
   approximation or unverified. A value with no source is listed as such, not passed off.
4. **Gaps are flagged, not filled by guesswork.** If no data can be found, the page says so
   and the gap goes to the project owner as a question.
